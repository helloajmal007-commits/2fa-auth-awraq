
# 🔐 2FA Live – Beginner Security Toolkit

A simple web app built with **TypeScript** that provides essential security tools in one place. This project is designed for learning purposes and beginner inspiration in web security and utility app development.

## 🚀 Features

* 🔑 **2FA Generator** – Generate time-based authentication codes
* 📱 **Enable 2FA Guide** – Learn how to set up 2FA on popular platforms
* 📷 **QR Code Generator** – Create QR codes for easy sharing
* 🛡️ **Password Manager (Basic)** – Store and manage passwords locally
* 📊 **Security Score Checker** – Get a basic overview of password strength
* ✍️ **Blog Section** – Learn about security tips and best practices

## 🌐 Live Demo

👉 https://2falive.alawraqstudio.com/

## 🎯 Purpose

This project is built for **beginners** who want to:

* Understand how 2FA works
* Explore basic security concepts
* Learn TypeScript-based web app development
* Get inspiration for building similar tools

## ⚠️ Disclaimer

This is a **demo / educational project** and not intended for production-level security use.
